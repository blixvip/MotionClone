Is every rebuild a perfect match?

No. Complex footage, 3D, tiny text, and unfamiliar fonts can differ. MotionClone compares the render with the reference so you can review what still needs work.

What do I need to run it?

Windows, Python 3.11+, Node.js 22+, FFmpeg, Chrome, and the official Codex CLI signed in with ChatGPT. The GitHub README covers setup.

Where do my videos go?

Projects are saved on your computer. Selected reference frames are sent to ChatGPT for scene analysis. This demo page does not accept uploads.
